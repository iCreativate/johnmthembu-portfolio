# Portfolio Images

Product screens and portfolio photography (warm ivory / charcoal / copper presentation).

## Structure

| Folder | Contents |
|--------|----------|
| `hero/` | Homepage collage (3 images) |
| `about/` | Portrait + studio |
| `projects/[slug]/` | `hero.png`, `thumbnail.png`, `gallery-*.png` |
| `ventures/` | One image per venture |

## Product screens

Live product captures are composited into 1536×1024 frames with soft warm backgrounds to match the portfolio presentation style:

- **PropReady** — https://propready.live
- **Timely Mate** — https://timelymate.app
- **Peboli** — https://peboli.store
- **iCreativate** — https://icreativate.co.za
- **TFT Bible Class** — https://tftbibleclass.org/
- **Zianda Agri-Hub** — https://zianda-agrihub.netlify.app/

Swap files in place — keep filenames, or update paths in `src/data/projects.ts` and `src/data/ventures.ts`.
